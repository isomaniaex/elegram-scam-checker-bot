🛡️ Suspicious Message Checker

Paste a suspicious message (fake support, watch-video job offer, or rapid-return investment) to spot red flags and see how to verify safely. Runs 100% locally in your browser.

Note: GitHub Pages hosts this static browser tool. To run the Telegram bot itself (bot.py), deploy it as a Python worker on a host like Railway, Render, Docker, or a Linux VPS.
